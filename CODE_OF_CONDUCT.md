# Code of Conduct

Be respectful, specific, and constructive.

This project welcomes technical disagreement, bug reports, security review, and alternative implementations. Harassment, personal attacks, discriminatory language, doxxing, or publishing private user data are not acceptable.

When reporting bugs, focus on reproducible behavior and technical evidence. Do not post private ChatGPT conversation content, authentication data, or another person's information.

Maintainers may edit, hide, or remove contributions that violate these expectations.
